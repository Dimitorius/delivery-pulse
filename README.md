# Delivery Pulse

Live delivery, flow and program metrics for Delivery Managers and Technical Program Managers.

**Status:** early build (stage 0: deployment pipeline). Spec: [docs/SPEC.md](docs/SPEC.md).

## What it will be

- An event-sourced simulator of a fictional program (5 teams, Scrum + Kanban), from which every metric is **computed**, not generated.
- ~50 live metrics: flow, Scrum, the five DORA metrics, PR/CI health, reliability, program dependencies, Monte Carlo forecasting, SAFe PI Predictability, AI impact.
- A full catalog of ~180 metrics with definitions, formulas, reading guides and sources.
- Diagnose mode: pick a symptom, get the bundle of metrics that confirms or rules it out.
